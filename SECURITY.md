# Security policy

Seyal is in early development (pre-alpha) and has no supported release yet.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report it privately through the code host's private vulnerability reporting (for example GitHub
"Report a vulnerability" under the Security tab) once the repository is published. Include steps
to reproduce and the impact you expect.

We aim to acknowledge reports within 7 days.
